# **关于7789屏幕驱动怎么使用**

* 仅需要修改，以下两行代码就可使（其余屏幕显示方向已在[st7789.py](st7789.py)写好）

把第11行 from ili9341 import ILI9341, BLACK, WHITE, RED, GREEN, BLUE, CYAN, YELLOW, GRAY, MAGENTA
更换为

from st7789 import ST7789V, BLACK, WHITE, RED, GREEN, BLUE, CYAN, YELLOW, GRAY, MAGENTA
#此为引入7789V屏幕

把64行 tft = ILI9341(spi1, cs=9, dc=12, rst=13)更换为

tft = ST7789V(spi1, cs=9, dc=12, rst=13, width=320, height=240)
#此为定义7789屏幕的显示方向等类型
