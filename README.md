1.**小部分的修改**	

*   本项目的**电路原理图**与原作者 [MisakaXing/RP2040-Based-LBJ-Receiver](原项目链接) 完全一致，

在原作者屏幕上，重新写了ST778V屏幕的兼容可见[st778.py](st7789.py)

**关于7789屏幕驱动怎么使用**

仅需要修改，以下两行代码就可使（其余屏幕显示方向已在[st778.py](st7789.py)写好）

from st7789 import ST7789V, BLACK, WHITE, RED, GREEN, BLUE, CYAN, YELLOW, GRAY, MAGENTA   
tft = ST7789V(spi1, cs=9, dc=12, rst=13, width=320, height=240)
