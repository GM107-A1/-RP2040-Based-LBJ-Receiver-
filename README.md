# -RP2040-Based-LBJ-Receiver-
基于RP2040-Based-LBJ-Receiver做出的修改



以下全是基于v5.0固件做出的更改

													
1 更改了作者的PCB设计，设计了兼容市面上其他类型屏幕大小的兼容，采样电阻更换为0805规格


2 增加了轨道起重车和轨道探伤车的显示，补全了其他车的显示（修改了显示缩放，显示轨道车只不显示）
起重轨道车-06（显示完整轨道车车次号 起重轨道车-06325）可见 iocos.json 文件

以下是类型的显示

3.0 增加了类型的显示，可显示旅客列车和货运列车的类型，可见 列车范围表.txt 文件

3.1 增加了例如（FK）两个字母开头的还有（0y）一类的检测 分别对应因故折返和空车底部回送等....

3.2 增加了DJ 0G 0D 这类比较含糊的类型 显示为动作检/回库

3.3 J SY Q J对应未列检列车 SY实验 Q抢险救灾 增加了此类显示的判断

3.4 增加了韶山系列（可以添加自定义车型）提示音（响两下）的提醒，绕过系统关闭嗡鸣器的限制

3.5 会看界面添加上年月日查看，为了限制把显示秒给去掉了

更改了中文显示菜单

4 翻译原作者菜单设置界面并翻译为中文显示

5 设计的新的外壳，完全兼容作者第五版PCB，增加热压螺母固定和金属挂扣，以及亚力克板保护,可见 3.1.STL 文件
